# Codex 本地额度悬浮面板（macOS）

这是原仓库的 macOS 原生实现：SwiftUI + AppKit，显示为可拖动、可缩放的无标题悬浮桌面面板。它没有也不会提供“贴附 Codex 顶部”的横条模式，也不包含 macOS 系统小组件扩展。

## 下载版运行（推荐）

要求：macOS 14 或更新版本。不需要 .NET、账号、API Key、网络访问或 Xcode。

1. 在 [v1.6.2 Release](https://github.com/yangyangha1/codex-local-quota-dashboard/releases/tag/v1.6.2) 下载 `CodexQuotaWidget-macOS-v1.6.2.zip`，解压得到 `CodexQuotaWidget.app`。
2. 将 App 拖入“应用程序”或任意本地目录后运行。它是普通悬浮面板，不是 macOS 系统小组件，也不会出现在“添加小组件”列表中。
3. 公开下载包**没有 Apple Developer ID 签名或公证**。首次启动若出现“无法验证开发者”，在 Finder 中按住 Control 点击 App，选择“打开”，再在确认框中选择“打开”；也可在“系统设置 → 隐私与安全性”中选择“仍要打开”。
4. 如系统仍拒绝打开，请先核对 Release 页面公布的 SHA-256，再执行：

```zsh
xattr -dr com.apple.quarantine /Applications/CodexQuotaWidget.app
```

菜单栏仪表图标左击会显示当前 5H／周额度百分比、各自重置时间和版本号；右击可打开主题、透明度、置顶、隐藏、开机自动启动和退出菜单。右键悬浮面板也可配置这些项目；实时主界面中，除“历史／明细”外任意位置按住即可拖动窗口。只有历史数据页的图表支持拖动框选放大；实时图表不拦截拖动。开机自动启动只创建本应用的 `com.yangyangha1.codex-local-quota-widget` 登录启动项，不影响其他 Codex 或系统启动项。

## 从源码构建

需要 macOS 14 或更新版本，以及 Apple Command Line Tools（`swift`）。

```zsh
cd macOS
./scripts/build-app.sh
open CodexQuotaWidget.app
```

开发期可直接运行：

```zsh
swift run
```

构建脚本会生成同时支持 Apple Silicon 和 Intel Mac 的通用 `.app`，但不会进行 Apple Developer ID 签名或公证。需要准备 GitHub 附件时运行：

```zsh
./scripts/package-release.sh
```

悬浮面板默认不置顶、无 Dock 图标；未置顶时位于普通应用窗口之后，可在菜单中手动开启“窗口置顶”。

## 保留的逻辑

- 只读 `~/.codex/sessions` 与 `~/.codex/archived_sessions` 的 JSONL；不上传、不联网、不读取提示词正文。
- 保留 64 KiB 分块读取、4 MiB 超长行跳过、未完成末行不提交、按文件偏移增量扫描、移动/截断/删除回滚与 35 天计数保留。
- 保留最近本地 5H／周额度快照、今日／近 7 天／近 30 天 Token、按需项目/session 明细、Token 速率／累计／额度图、1/2/3/6/12/24/48 小时视图、滚轮缩放与框选时间段。
- 保留 30 秒采样、5 分钟批量写入、104 字节 `CLDHST04` v4 双额度历史记录、校验和、兼容读取旧 96 字节 `CLDHST03` v3 文件、8 MB 分级压缩与历史日期视图。新 v4 文件独立写入，原 v3 文件不会被改写。

历史文件放在 `~/Library/Application Support/CodexLocalDashboard/`，只含时间、四类计数和额度快照；不含 prompt、回复、session 名或项目路径。

## v1.6.2 界面对齐

本地 macOS 版以原仓库 v1.5.5 为功能基线：

- 初始尺寸为 400×434；窗口支持自由宽高缩放，最小为 256×278、最大为 576×625。顶部左侧显示无小数的“GPT·xx% / xx%”：5H 数值为橙色，周数值为绿色，不显示窗口名称；周额度剩余条是底层上限，5H 条按其剩余比例叠加固定 80% 不透明度的橙色斜纹，绝不会超过周额度可用范围。右侧“历史”和“明细”与其垂直居中对齐。下一行显示“5H重置 · 周重置”。面板不显示版本号；菜单栏图标左击显示的额度浮层中保留可点击的版本号。
- “明细”默认只显示今天有活动的会话，可切换“显示全部／仅今天”；项目和会话整行均可展开。会话按项目内最新活动顺序编号，并显示最新活动日期时间；项目位置／会话文件定位按钮使用清晰的文字和图标。
- 图表上方依次显示灰色“xH消耗”、绿色“周 x%”、灰色“/”、橙色“5H x%”；灰色“速率 0/分”在左右文字之间的空余区域居中，蓝色“累计 Token”右对齐，并随可用宽度缩放以完整显示。图内始终在同一时间坐标中绘制周额度剩余、70% 不透明度的橙色 5H 剩余、灰色速率曲线（紫色面积填充）和累计 Token，不再提供速率单图或三线切换按钮。历史回放复用同一绘制逻辑，并在旧记录没有 5H 数据时只显示原有曲线。各曲线各自按原算法的数值上限缩放，不会被错误地归一化为同一单位。
- 历史页隐藏“今日／近 7 天／近 30 天”汇总，保留“历史数据”标题控制行及独立的 7 天日期行；两页共用同一固定高度的中间区域与图表组件，因此消耗额度行和图表高度保持一致。
- 图内纵向保留 5 个等深网格，横轴保留 7 个时间刻度：24 小时及以内显示 HH:mm，48 小时视图显示 MM-dd；历史图可在图内拖动框选时间段放大。选中后会显示实际横轴范围和“恢复全天”入口；滚轮也会取消框选并切换时间范围。

## 缓存边界

- 本次运行：内存中的文件偏移、日汇总与 48 小时图表点，应用退出即释放。
- 项目持久化：上述隐私最小化的历史二进制文件；读写使用独立句柄与跨进程 `flock`。
- 不建立任何含账号、Cookie、令牌或会话正文的全局缓存。
